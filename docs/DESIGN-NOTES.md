# Dirección visual V4

## Lectura

Eucaten se presenta como una consultora contemporánea y boutique. La innovación está en la experiencia y en el movimiento, no en símbolos tecnológicos.

## Sistema visual

- marfil cálido como base;
- grafito para autoridad;
- bordó profundo como acento;
- serif editorial para títulos y sans discreta para interfaz;
- documentos, papel, fotografía y composición editorial como mundo visual;
- asimetría controlada;
- movimiento amplio pero lento.

## Lo que se evita

- estética cyber / nodos / dashboards;
- azul corporativo automático;
- cards SaaS genéricas;
- frases inventadas que Cata nunca dijo;
- animaciones que oculten contenido si JavaScript falla.
